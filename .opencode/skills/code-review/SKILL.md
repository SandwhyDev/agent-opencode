# Code Review Skill

Review actual implementation.

## Priority

Look for:

1. Bugs
2. Security issues
3. Data integrity issues
4. Regressions
5. Performance problems
6. Architecture violations
7. Maintainability problems
8. Unnecessary complexity

## Review Principle

Do not reject code merely because you would write it differently.

Prefer the smallest appropriate implementation that follows the existing architecture.

## Findings

For each important finding include:

- Severity
- File
- Problem
- Why it matters
- Recommended action

Focus on actionable findings.
