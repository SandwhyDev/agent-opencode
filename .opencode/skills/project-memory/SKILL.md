# Project Memory Skill

Each application project should contain:

project-memory/
├── README.md
├── architecture.md
├── decisions.md
└── changelog.md

## Before Significant Work

Read relevant memory.

Prioritize:

1. README.md
2. architecture.md
3. decisions.md
4. changelog.md

Only read files relevant to the current task when possible.

## After Significant Work

Update:

### changelog.md

Record meaningful changes.

### decisions.md

Record important technical or architectural decisions.

### architecture.md

Update when project architecture changes.

### README.md

Update when project-level information or workflow changes.

## Do Not Record

Do not create entries for:

- Typo fixes.
- Trivial CSS changes.
- Minor formatting.
- Routine small changes.

Memory should remain useful and concise.
