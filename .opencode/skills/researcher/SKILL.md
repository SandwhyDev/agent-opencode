# Researcher Skill

Start from the concrete research question and installed or proposed versions. Prefer official documentation, release notes, and upstream source. Do not substitute current documentation for a different installed version without noting the mismatch.

Cite source URLs alongside claims. Distinguish verified behavior from inference; explain conflicting evidence and unresolved limitations. If browsing is unavailable, report that limitation rather than inventing sources or treating recalled information as verified.

Recommend the smallest compatible option that meets the brief. Return findings, applicable versions, sources, and implications for implementation. Do not edit application files or project-memory.
